COMBAT, SPELL AND ANIMATION CONSOLIDATION
Completed 2026-10-31

RESULT

Story and Create now execute gameplay through CombatWorld/CombatRuntime rather
than maintaining separate projectile, impact, cast-payment and melee mechanics.
A new mode can inherit CombatWorld directly, spawn the existing combatants and
submit authored spells. It does not need either mode's UI or campaign scene.
See docs/combat-runtime.txt for the integration example and ownership contracts.

WORK COMPLETED

- Shared cast eligibility and atomic mana/stamina payment, including casting
  limb restrictions and per-character God Mode. Create's Play/release uses this
  same path as gameplay.
- Shared spell effect dispatch: projectiles, ground shots, healing, armor, haste,
  burst, beam, ice beam, nova and earth summon. Target selection and presentation
  remain hooks, not second implementations of damage or cost.
- Shared projectile launch/prediction preparation, flight, world contacts, guard
  absorption, area impacts, physical damage, status application and telemetry.
  Caster movement is captured once at launch; one projectile cannot double-pay
  costs or double-apply its movement bonus.
- Shared actor updates, wall/structure impacts, hurtbox updates and melee steps.
- Shared swept melee contacts, attack windows, limb-speed/charge rules, manual
  blocking and impact dispatch. Removed the extra per-limb melee hit/damage
  accounting after the common impact path had already recorded that hit.
- Moved authored spell calculations and neutral elementless content out of UI:
  duration, stamina, physical damage, release timing, mana, amp, size/speed/effect
  allocation, and the reusable neutral 10/10/10 factory.
- Shared idle resource-pool recovery and shared animation pose capture/blending.
  Existing animation sampling, aim corrections and cached channel filtering are
  reused; animation players and editing state remain independent per actor.
- Explicit authored Fire/Ice/Lightning effects now work in Story. Its stage-one
  hand-to-hand restriction still suppresses old implicit team effects; it no
  longer suppresses an explicit elemental spell.
- Separated old grassland presentation utilities and spell catalog from the
  visual-only spell study. Gameplay no longer inherits that demo's simplified
  projectile loop.
- Made shared combat logging an optional host service, so importing the reusable
  world does not require compiling against a UI/autoload global.
- Added the new-mode contract test and documented the architecture in AGENTS.md.

LEVEL-INDEPENDENCE FOLLOW-UP (2026-10-31)

bounds, local spawns and terrain queries. Generic combat no longer imports the
pit's radius, steers toward global zero, or invents a floor at height zero.
The existing pit supplies its own saved level resource. Unspecified/generated
maps default to unbounded play areas. See docs/combat-levels.txt.

INTERRUPTED-CAST STAMINA (2026-10-31)

Unreleased casts now retain stamina cost in proportion to the animation already
performed. Example: interrupting a 10-stamina, 1-second cast at 0.25 seconds costs
2.5 stamina. Repeated restarts accumulate these costs. The shared runtime snapshots
the original cost/duration, so changing settings cannot rewrite the old debt.
Mana still pays at release. A successful release pays its full normal stamina
cost once; interrupting its recovery adds no second charge. God Mode remains
unlimited, interruption cannot overdraw stamina, and explicit resets clear debt.
Native actor mode exits and editor restart/stop/switch paths share the accounting.

Passed the dedicated cancellation test through actual key-1 input and native
actor casting/hit interruption, plus resource synchronization, casting shortcuts,
limiter controls, neutral actual damage and the independent-mode runtime contract.
Limiter validation also exposed an old inherited percentage overriding the raw
mana input; raw specs now remove that percentage and honor their final mana value.
The limiter test explicitly disables God Mode and waits for asynchronous window
focus rather than assuming focus is restored in a single frame.

Implementation: +80 / -4 lines. Tests: +87 / -4 lines.
