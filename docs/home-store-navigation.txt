Standalone Home animation Store

Home > Store opens scenes/animation_store.tscn and animation_store_screen.gd.
It loads the reusable pit map, one preview actor, and Store controls. It does
not load animation_editor.gd, spell_builder.gd, the custom frame editor,
timeline UI, or saved custom-animation frame files. Account-owned metadata is
read so Downloaded items stay visible; bulk animation resources load on Play or
Download. The LHS is anchored below the header to the bottom, with no floating
header, resize script, drag handles, or border adjustment.

animation_store_backend.gd owns the existing index/query, 20-item page hydration,
filters/preferences, creator ranking, blocking, source import, quality gate,
and acquisition workflow. The legacy editor methods delegate to this same
backend. Downloads still use animation_store_library.gd and
animation_project_assets.gd: same account cfg, unique names, provenance and
project-copy manifest, same Downloaded folders. Bulk source assets stay local.

Home, page navigation and row actions use icons with tooltips and keyboard
focus. Filters and animation rows have type/state icons, with readable names.
Ctrl+wheel or Ctrl+middle-drag zooms Store controls; the setting persists in
user://animation_store_view.cfg. Outside the panel, wheel zooms the preview
camera and middle-drag orbits it. Escape / Home icon returns Main Menu.

Preview uses shared spell_cast_motion.gd pose sampling, retargeting and safety,
with short entry/exit blends and a single actor, not a second animation editor.
standalone_store_test.gd verifies the editor scripts are absent from Godot's
resource cache, actual cartwheel bone movement, fixed layout, paginated rows,
and the shared download pipeline without writing to the user's inventory.

Create's removed icon row remains absent. Settings and Controls are under
Home > Options; F9 opens universal settings in any mode.

Store movement and type browsing (2026-11-02)
- WASD moves the preview actor; Shift sprints. Shared CharacterMovement,
  CreationLocomotion, actor sprint/resource rules and CombatWorld terrain movement
  supply the behavior. Search/text entry suppresses movement; focus loss clears keys.
- The inspection camera follows translation without losing its orbit or zoom.
- Store filters use Arm, Leg, Head and Movement. Compact metadata carries
  store_animation_type, so filtering still loads only 20 detail records per page.
- AnimationStoreTypes preserves explicit authored types. Other entries use label,
  category and tag hints, with whole-motion actions taking precedence and unknown
  clips falling back to Movement. These browsing hints do not change combat types.
- Body-part metadata and body: searches remain available; type: searches are added.
- Cache version 5 rebuilds the local metadata index once. Source assets, creator
  credits and account ownership remain intact; old body-filter indices are ignored.
